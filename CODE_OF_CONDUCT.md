# Code of Conduct

## Standard

Treat contributors with respect. Discuss technical claims using evidence. Critique ideas and code without attacking people.

Harassment, discrimination, threats, deliberate exposure of private information, and repeated disruptive behavior are not accepted.

## Enforcement

Report conduct problems privately to the repository owner. Reports will be reviewed in context. Proportionate action may include a warning, removal of content, temporary restriction, or permanent exclusion.
